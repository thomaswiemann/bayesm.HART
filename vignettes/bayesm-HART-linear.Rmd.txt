## Introduction
  
This vignette estimates a hierarchical linear model with HART priors
using `bayesm.HART`, applied to the `orangeJuice` scanner panel dataset
from `bayesm`. The HART prior specifies the *representative store* as a
sum-of-trees function of observed demographics, $\Delta(Z_i)$, whereas
the conventional specification uses the linear form $\Delta^\top Z_i$.

## Orange Juice Scanner Panel Data

The `orangeJuice` dataset contains weekly store-level scanner data for 83 stores. We observe log-sales, prices of 11 brands, and deal/feature indicators. Store demographics (income, education, ethnicity, household size, etc.) serve as covariates $Z_i$. Following Montgomery (1997), we estimate a log-log demand model for brand 1 (Tropicana Premium 64 oz), so coefficients are directly interpretable as price elasticities.

```{r setup}
library(bayesm.HART)
library(bayesm)
library(tidyr)
library(dplyr)
library(ggplot2)

data(orangeJuice)
yx <- orangeJuice[["yx"]]
storedemo <- orangeJuice[["storedemo"]]

brand1 <- yx[yx[["brand"]] == 1, ]

# Build per-store regdata (following bayesm::orangeJuice documentation)
store_ids <- storedemo[["STORE"]]
nreg <- length(store_ids)
regdata <- vector("list", length = nreg)
price_cols <- paste0("price", 1:11)
for (i in 1:nreg) {
  si <- brand1[brand1[["store"]] == store_ids[i], ]
  y <- si[["logmove"]]
  X <- cbind(1, log(as.matrix(si[, price_cols])), si[["deal"]], si[["feat"]])
  colnames(X) <- c("Intercept", paste0("Log Price ", 1:11), "Deal", "Feature")
  regdata[[i]] <- list(y = y, X = X)
}

Z <- as.matrix(storedemo[, -1])
Z <- t(t(Z) - colMeans(Z))  # bayesm requires de-meaned Z

Data <- list(regdata = regdata, Z = Z)
```

## MCMC Estimation

We fit both the HART model (Wiemann, 2025) and a conventional linear hierarchical model (Rossi et al., 2009). Both estimate store-specific coefficients $\beta_i$ via a hierarchical linear model; they differ only in their specification of $\Delta(\cdot)$. The linear model is fitted with `bayesm::rhierLinearMixture`, which does not return a log-likelihood, so its trace is computed from the draws. A short chain of 20,000 iterations is used here for illustration; longer chains should be run in practice.

```{r fit-models, cache = TRUE, results = "hide"}
set.seed(2025)
R <- 20000
keep <- 4
burn <- 250  # kept draws to discard
Mcmc <- list(R = R, keep = keep)

out_hart <- bayesm.HART::rhierLinearMixture(
  Data = Data, Mcmc = Mcmc,
  Prior = list(ncomp = 1, hart_model = "normalized",
               bart = list(num_trees = 20))
)

out_lin <- bayesm::rhierLinearMixture(Data, Prior = list(ncomp = 1), Mcmc)
class(out_lin) <- "rhierLinearMixture"  # bayesm.HART methods for the bayesm fit
out_lin$loglike <- sapply(seq_len(R / keep), function(s)
  sum(sapply(seq_along(regdata), function(i)
    sum(dnorm(regdata[[i]]$y, regdata[[i]]$X %*% out_lin$betadraw[i, , s],
              sqrt(out_lin$taudraw[s, i]), log = TRUE)))))
```

We use the log-likelihood trace as a basic MCMC diagnostic.

```{r mcmc-diagnostics, fig.width=8, fig.height=5, fig.align='center', out.width="90%", dpi = 200, fig.cap="MCMC Traceplot of the Log Likelihood."}
models <- c("Linear", "HART")
trace <- data.frame(
  Iteration = rep(seq_len(R / keep) * keep, 2),
  Model = rep(models, each = R / keep),
  LogLikelihood = c(out_lin$loglike, out_hart$loglike)
)

ggplot(trace, aes(x = Iteration, y = LogLikelihood, color = Model)) +
  geom_line(alpha = 0.8) +
  geom_vline(xintercept = burn * keep, linetype = "dashed") +
  theme_classic(base_size = 16) +
  theme(legend.position = "bottom", legend.title = element_blank()) +
  labs(title = "Log-Likelihood Trace Plots", x = "MCMC Iteration", y = "Log-Likelihood")
```

## Posterior Inference about Store-level Coefficients

We compare posterior distributions of the own-price elasticity for two stores: Store 25 (high `INCOME`, high `EDUC`) and Store 79 (low `INCOME`, high `ETHNIC`, the share of Black and Hispanic residents).

```{r individual-betas, fig.width=12, fig.height=6, fig.align='center', out.width="90%", dpi = 200, fig.cap="Posterior Distributions of Store-level Own-Price Elasticities."}
stores <- c(25, 79)
k <- 2  # "Log Price 1", the own-price elasticity

beta_draws <- bind_rows(
  Linear = as.data.frame(t(out_lin$betadraw[stores, k, -(1:burn)])),
  HART   = as.data.frame(t(out_hart$betadraw[stores, k, -(1:burn)])),
  .id = "Model"
) %>%
  setNames(c("Model", "Store 25", "Store 79")) %>%
  pivot_longer(-Model, names_to = "Store", values_to = "Coefficient") %>%
  mutate(Model = factor(Model, levels = models))

ggplot(beta_draws, aes(x = Coefficient, fill = Store)) +
  geom_histogram(aes(y = after_stat(density)), bins = 45, alpha = 0.6,
                 position = "identity") +
  facet_wrap(~Model) +
  theme_classic(base_size = 16) +
  theme(legend.position = "top", legend.title = element_blank()) +
  labs(title = "Selected Posterior Distributions of Store-level Own-Price Elasticity",
       x = "Elasticity", y = "Density")
```

```{r individual-betas-summary}
beta_draws %>%
  group_by(Model, Store) %>%
  summarise(Mean = mean(Coefficient), SD = sd(Coefficient), .groups = "drop")
```

Both models produce similar store-level elasticity estimates for the
selected stores. With about 116 weekly observations per store, the
individual likelihood contributes most of the posterior information at
the store level in this application.

## Posterior Inference on Store Segment Coefficients

The models differ in how they characterize the expected coefficient $\Delta(Z)$ for a representative store with demographics $Z$. We compare these segment-level predictions for the same two stores, using the `predict` function.

```{r representative-store, results = "hide", fig.width=12, fig.height=6, fig.align='center', out.width="90%", dpi = 200, fig.cap="Posterior Distributions of Expected Store Segment Coefficients."}
Z_seg <- list(Z = Z[stores, ])
DeltaZ_lin  <- predict(out_lin, newdata = Z_seg, type = "DeltaZ+mu", burn = burn)
DeltaZ_hart <- predict(out_hart, newdata = Z_seg, type = "DeltaZ+mu", burn = burn)

deltaZ_draws <- bind_rows(
  Linear = as.data.frame(t(DeltaZ_lin[, k, ])),
  HART   = as.data.frame(t(DeltaZ_hart[, k, ])),
  .id = "Model"
) %>%
  setNames(c("Model", "Segment 1", "Segment 2")) %>%
  pivot_longer(-Model, names_to = "Segment", values_to = "Coefficient") %>%
  mutate(Model = factor(Model, levels = models))

ggplot(deltaZ_draws, aes(x = Coefficient, fill = Segment)) +
  geom_histogram(aes(y = after_stat(density)), bins = 45, alpha = 0.6,
                 position = "identity") +
  facet_wrap(~Model) +
  theme_classic(base_size = 16) +
  theme(legend.position = "top", legend.title = element_blank()) +
  labs(title = "Posterior Distributions of Expected Own-Price Elasticities",
       x = "Elasticity", y = "Density")
```

```{r segment-comparison}
deltaZ_draws %>%
  group_by(Model, Segment) %>%
  summarise(Mean = mean(Coefficient), SD = sd(Coefficient), .groups = "drop")
```

The linear specification restricts segment means to an affine function
of demographics. HART allows nonlinear and interaction structure in
$Z$ through $\Delta(Z)$.
