## Introduction

The companion article [`simulation-convergence`](simulation-convergence.html)
asks whether the samplers recover an analytic truth. This one asks a
different question: when the truth is what one of these models actually
says about real data, which model wins, and what does misspecification
cost?

Three specifications are fitted once to the `margarine` household panel:
the linear hierarchical logit of `bayesm`, direct HART with one covariance
shared by all households (`hart_cov = "constant"`), and direct HART with
covariate-dependent covariance (`hart_cov = "heteroskedastic"`). Their
posterior means define three fixed data-generating processes. Data are then
simulated from each and all three are fitted back, giving a matrix of true
model by fitted model: the diagonal measures recovery under correct
specification, the off-diagonal the cost of getting it wrong in either
direction.

Calibration fixes the shapes, not the sample size. The demographics, the
brand set and the price distribution are the real ones; the number of
households and the number of purchase occasions are then free, so the same
grid in `n` and `T` as the analytic study applies.

Margarine was chosen by measurement. The share of coefficient variance that
the covariates explain, on the same diagnostic used for the analytic
designs, is 0.16 here against 0.08 for the `orangeJuice` store panel and
0.03 for the `bank` conjoint. Age, income and gender in the `bank` study
explain so little of how respondents differ that no mean model can be told
from another on it.

## The Margarine Panel

356 households with at least five purchases choose among ten margarine
brands, with the ten shelf prices observed at each occasion and five
demographics: income, family size, college, white collar and retired. The
coefficients are nine brand intercepts and one price sensitivity.

```{r margarine-data}
n_brand <- 10L

# One purchase occasion: nine brand intercepts and the shelf price.
occasion_rows <- function(price)
  cbind(rbind(diag(n_brand - 1L), 0), price)

margarine_data <- function(min_purchases = 5L) {
  e <- new.env()
  utils::data(margarine, package = "bayesm", envir = e)
  cp <- e$margarine$choicePrice
  dm <- e$margarine$demos
  hh <- intersect(unique(cp$hhid), dm$hhid)
  hh <- hh[table(cp$hhid)[as.character(hh)] >= min_purchases]
  Z  <- as.matrix(dm[match(hh, dm$hhid),
                     c("Income", "Fam_Size", "college", "whtcollar",
                       "retired")])
  Z   <- t(t(Z) - colMeans(Z))               # centered, as rhier* requires
  key <- apply(Z, 1, paste, collapse = "|")
  first <- !duplicated(key)
  list(hh = hh,
       choice = lapply(hh, function(h) as.integer(cp$choice[cp$hhid == h])),
       price  = lapply(hh, function(h) as.matrix(cp[cp$hhid == h, 3:12])),
       pool = as.matrix(cp[, 3:12]),        # all observed price vectors
       Z = Z, Z_unique = Z[first, , drop = FALSE],
       z_index = match(key, key[first]), nvar = n_brand)
}#MARGARINE_DATA
```

## Calibration

The three models are fitted once to the real purchases with 5,000 draws,
keeping every fifth and dropping the first 200 kept. Only the implied truth
is stored: the posterior mean of \eqn{\Delta(Z_u) + \mu} and of
\eqn{\Sigma(Z_u)} at the covariate patterns.

```{r calibration-setup}
fit_priors <- list(
  linear = list(ncomp = 1),
  direct_constant = list(ncomp = 1, hart_model = "direct",
                         hart_cov = "constant",
                         bart = list(num_trees = 200), store_trees = FALSE),
  direct_hetero = list(ncomp = 1, hart_model = "direct",
                       hart_cov = "heteroskedastic",
                       bart = list(num_trees = 200),
                       vartree = list(num_trees = 20),
                       phitree = list(num_trees = 20), store_trees = FALSE))
truths <- names(fit_priors)

# Posterior means of Delta(Z_u) + mu and Sigma(Z_u): the generating values.
extract_truth <- function(fit, Z_unique, burn) {
  dz <- predict(fit, newdata = list(Z = Z_unique), type = "DeltaZ+mu",
                burn = burn, r_verbose = FALSE)
  sg <- predict(fit, newdata = list(Z = Z_unique), type = "SigmaZ",
                burn = burn, r_verbose = FALSE)
  list(Delta = apply(dz, 1:2, mean), Sigma = apply(sg, 1:3, mean))
}#EXTRACT_TRUTH
```

\eqn{E\{\Sigma_{dd}(Z)\}}.

## Generating

A data set draws `n` households by resampling the observed demographic
rows, takes each one's frozen \eqn{\Delta} and \eqn{\Sigma}, draws
\eqn{\theta_i \sim N(\Delta_i, \Sigma_i)}, and then `T` purchase occasions
whose price vectors are resampled from the pooled observed prices. Four
further occasions are held out.

The resampled covariates are re-centered, as the samplers require, so the
truth travels with the household rather than with the covariate value. A
location shift in `Z` is absorbed into \eqn{\mu}, and both the linear and
the tree mean models can represent the shifted function, so nothing is lost
by it.

```{r generate}
n_holdout <- 4L

simulate_cell <- function(truth, n, T, rep) {
  tr   <- truth_set[[truth]]
  nvar <- mg$nvar
  set.seed(400000L * match(truth, truths) + 7919L * rep + 31L * n + T)
  idx  <- sample(nrow(mg$Z), n, replace = TRUE)
  pat  <- mg$z_index[idx]
  Zs   <- mg$Z[idx, , drop = FALSE]
  Zs   <- t(t(Zs) - colMeans(Zs))
  root <- lapply(seq_len(nrow(tr$Delta)), function(u) chol(tr$Sigma[u, , ]))
  theta <- t(vapply(seq_len(n), function(i)
    as.vector(rnorm(nvar) %*% root[[pat[i]]]) + tr$Delta[pat[i], ],
    numeric(nvar)))
  lgt <- vector("list", n); holdout <- vector("list", n)
  for (i in seq_len(n)) {
    pr <- mg$pool[sample(nrow(mg$pool), T + n_holdout, replace = TRUE), ,
                  drop = FALSE]
    Xall <- lapply(seq_len(nrow(pr)), function(t) occasion_rows(pr[t, ]))
    y <- vapply(Xall, function(X) {
      u <- as.vector(X %*% theta[i, ])
      sample.int(n_brand, 1L, prob = exp(u - max(u)))
    }, integer(1))
    lgt[[i]] <- list(y = y[seq_len(T)],
                     X = do.call(rbind, Xall[seq_len(T)]))
    holdout[[i]] <- list(y = y[T + seq_len(n_holdout)],
                         X = Xall[T + seq_len(n_holdout)])
  }
  list(Data = list(lgtdata = lgt, Z = Zs, p = n_brand),
       theta = theta, pattern = pat, Z = Zs, holdout = holdout)
}#SIMULATE_CELL
```

Scoring compares posterior means with the frozen truth: \eqn{\theta_i} per
household, and \eqn{\Delta} and \eqn{\Sigma} at the covariate patterns the
cell happens to contain. Held-out occasions are scored by hit rate and mean
log-likelihood.

```{r score}
lower_cor <- function(S) {
  d <- sqrt(diag(S))
  R <- S / outer(d, d)
  R[lower.tri(R)]
}#LOWER_COR

score_fit <- function(fit, sim, truth, burn) {
  tr   <- truth_set[[truth]]
  nvar <- mg$nvar
  kept <- (burn + 1):dim(fit$betadraw)[3]
  beta <- fit$betadraw[, , kept, drop = FALSE]
  lo   <- apply(beta, c(1, 2), quantile, probs = 0.05)
  hi   <- apply(beta, c(1, 2), quantile, probs = 0.95)
  bbar <- apply(beta, c(1, 2), mean)
  # Delta and Sigma at the distinct covariate rows this cell contains.
  u    <- !duplicated(sim$pattern)
  Zu   <- sim$Z[u, , drop = FALSE]
  pu   <- sim$pattern[u]
  dz <- predict(fit, newdata = list(Z = Zu), type = "DeltaZ+mu", burn = burn,
                r_verbose = FALSE)
  sg <- predict(fit, newdata = list(Z = Zu), type = "SigmaZ", burn = burn,
                r_verbose = FALSE)
  dlo <- apply(dz, c(1, 2), quantile, probs = 0.05)
  dhi <- apply(dz, c(1, 2), quantile, probs = 0.95)
  Dhat <- apply(dz, 1:2, mean); Shat <- apply(sg, 1:3, mean)
  Dtru <- tr$Delta[pu, , drop = FALSE]
  logv <- vapply(seq_along(pu), function(k)
    log(diag(Shat[k, , ])) - log(diag(tr$Sigma[pu[k], , ])), numeric(nvar))
  rho  <- vapply(seq_along(pu), function(k)
    lower_cor(Shat[k, , ]) - lower_cor(tr$Sigma[pu[k], , ]),
    numeric(nvar * (nvar - 1) / 2))
  hit <- ll <- numeric(length(sim$holdout))
  for (i in seq_along(sim$holdout)) {
    h <- sim$holdout[[i]]
    pr <- vapply(seq_along(h$y), function(t) {
      e <- exp(as.vector(h$X[[t]] %*% bbar[i, ]))
      e[h$y[t]] / sum(e)
    }, numeric(1))
    top <- vapply(seq_along(h$y), function(t) {
      e <- as.vector(h$X[[t]] %*% bbar[i, ])
      which.max(e) == h$y[t]
    }, logical(1))
    hit[i] <- mean(top); ll[i] <- mean(log(pr))
  }
  data.frame(
    rmse_beta   = sqrt(mean((bbar - sim$theta)^2)),
    cover_beta  = mean(lo <= sim$theta & sim$theta <= hi),
    rmse_delta  = sqrt(mean((Dhat - Dtru)^2)),
    cover_delta = mean(dlo <= Dtru & Dtru <= dhi),
    rmse_logv   = sqrt(mean(logv^2)),
    rmse_rho    = sqrt(mean(rho^2)),
    holdout_hit = mean(hit), holdout_ll = mean(ll))
}#SCORE_FIT
```

```{r run-cell}
cache_dir <- file.path(vignette_cache_dir, "sim-calibrated")
dir.create(cache_dir, showWarnings = FALSE)

score_cell <- function(truth, n, T, rep, fitted)
  tryCatch(fit_cell(truth, n, T, rep, fitted), error = function(e) e)

fit_cell <- function(truth, n, T, rep, fitted) {
  file <- file.path(cache_dir, sprintf("%s-n%d-T%d-rep%d-%s.rds",
                                       truth, n, T, rep, fitted))
  if (file.exists(file)) return(readRDS(file))
  sim <- simulate_cell(truth, n, T, rep)
  set.seed(600000L * match(truth, truths) + 7919L * rep + 31L * n + T +
             match(fitted, truths))
  t0 <- Sys.time()
  capture.output(fit <- rhierMnlRwMixture(
    Data = sim$Data, Prior = fit_priors[[fitted]],
    Mcmc = list(R = R, keep = keep, nprint = 0L), r_verbose = FALSE))
  out <- cbind(
    data.frame(truth = truth, n = n, T = T, rep = rep, fitted = fitted,
               seconds = as.numeric(Sys.time() - t0, units = "secs"),
               version = as.character(packageVersion("bayesm.HART")),
               stringsAsFactors = FALSE),
    score_fit(fit, sim, truth, burn))
  saveRDS(out, file, compress = "xz", version = 2)
  out
}#FIT_CELL
```

```{r run}
ncores <- if (.Platform$OS.type == "windows") 1L else
```

## Extending the Study

The three truths live in one small file of posterior means; deleting it
refits them. Every `(truth, n, T, rep, fitted)` cell is its own file, so
adding replications, sample sizes, occasion counts or a fourth
specification only fits what is new.
