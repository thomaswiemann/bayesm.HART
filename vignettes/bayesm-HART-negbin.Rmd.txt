## Introduction
  
This vignette estimates a hierarchical negative binomial model with HART
priors using `bayesm.HART`, applied to the `detailing` pharmaceutical
panel dataset from `bayesm`. The HART prior specifies the
*representative physician* as a sum-of-trees function of observed
characteristics, $\Delta(Z_i)$, whereas the conventional specification
uses the linear form $\Delta^\top Z_i$.

## Pharmaceutical Detailing Data

The `detailing` dataset contains a balanced panel of 1,000 physicians observed over 23 months. For each physician-month, we observe prescriptions written (`scripts`), detailing visits (`detailing`), and lagged prescriptions (`lagged_scripts`). Physician demographics (`generalphys`, `specialist`, `mean_samples`) serve as covariates $Z_i$.

```{r setup}
library(bayesm.HART)
library(bayesm)
library(tidyr)
library(dplyr)
library(ggplot2)

data(detailing)
counts <- detailing[["counts"]]
demo <- detailing[["demo"]]

phys_ids <- demo[["id"]]
nreg <- length(phys_ids)
regdata <- vector("list", length = nreg)
for (i in 1:nreg) {
  si <- counts[counts[["id"]] == phys_ids[i], ]
  y <- si[["scripts"]]
  X <- cbind(1, as.matrix(si[, c("detailing", "lagged_scripts")]))
  colnames(X) <- c("Intercept", "Detailing", "Lagged Scripts")
  regdata[[i]] <- list(y = y, X = X)
}

Z <- as.matrix(demo[, -1])
# De-mean continuous columns only; leave binary indicators as-is
Z[, "mean_samples"] <- Z[, "mean_samples"] - mean(Z[, "mean_samples"])

Data <- list(regdata = regdata, Z = Z)
```

## MCMC Estimation

We fit both the HART model (Wiemann, 2025) and a conventional linear hierarchical model (Rossi et al., 2009). Both estimate physician-specific coefficients $\beta_i$ via hierarchical negative binomial regression with shared overdispersion $\alpha$; they differ only in their specification of $\Delta(\cdot)$. Both are fitted with `bayesm.HART::rhierNegbinRw`: in `bayesm` 3.1-7, `rhierNegbinRw` stops unless $\alpha$ is fixed. The sampler uses Metropolis-Hastings (the negative binomial likelihood is not conjugate), so a longer chain is recommended.

```{r fit-models, cache = TRUE, results = "hide"}
set.seed(2025)
R <- 40000
keep <- 4
burn <- 1000  # kept draws to discard
Mcmc <- list(R = R, keep = keep)

out_hart <- bayesm.HART::rhierNegbinRw(
  Data = Data, Mcmc = Mcmc,
  Prior = list(ncomp = 1, hart_model = "normalized",
               bart = list(num_trees = 20))
)

out_lin <- bayesm.HART::rhierNegbinRw(Data = Data, Mcmc = Mcmc,
                                      Prior = list(ncomp = 1))
```

We use the log-likelihood trace as a basic MCMC diagnostic.

```{r mcmc-diagnostics, fig.width=8, fig.height=5, fig.align='center', out.width="90%", dpi = 200, fig.cap="MCMC Traceplot of the Log Likelihood."}
models <- c("Linear", "HART")
trace <- data.frame(
  Iteration = rep(seq_len(R / keep) * keep, 2),
  Model = rep(models, each = R / keep),
  LogLikelihood = c(out_lin$loglike, out_hart$loglike)
)

ggplot(trace, aes(x = Iteration, y = LogLikelihood, color = Model)) +
  geom_line(alpha = 0.8) +
  geom_vline(xintercept = burn * keep, linetype = "dashed") +
  theme_classic(base_size = 16) +
  theme(legend.position = "bottom", legend.title = element_blank()) +
  labs(title = "Log-Likelihood Trace Plots", x = "MCMC Iteration", y = "Log-Likelihood")
```

## Posterior Inference about Physician-level Coefficients

We compare posterior distributions of the detailing coefficient for two physicians: Physician 840 (GP, no samples) and Physician 888 (specialist, many samples).

```{r individual-betas, fig.width=12, fig.height=6, fig.align='center', out.width="90%", dpi = 200, fig.cap="Posterior Distributions of Physician-level Detailing Coefficients."}
physicians <- c(840, 888)
k <- 2  # Detailing

beta_draws <- bind_rows(
  Linear = as.data.frame(t(out_lin$betadraw[physicians, k, -(1:burn)])),
  HART   = as.data.frame(t(out_hart$betadraw[physicians, k, -(1:burn)])),
  .id = "Model"
) %>%
  setNames(c("Model", "Physician 840", "Physician 888")) %>%
  pivot_longer(-Model, names_to = "Physician", values_to = "Coefficient") %>%
  mutate(Model = factor(Model, levels = models))

ggplot(beta_draws, aes(x = Coefficient, fill = Physician)) +
  geom_histogram(aes(y = after_stat(density)), bins = 45, alpha = 0.6,
                 position = "identity") +
  facet_wrap(~Model) +
  theme_classic(base_size = 16) +
  theme(legend.position = "top", legend.title = element_blank()) +
  labs(title = "Selected Posterior Distributions of Physician-level Detailing Coefficients",
       x = "Coefficient Value", y = "Density")
```

```{r individual-betas-summary}
beta_draws %>%
  group_by(Model, Physician) %>%
  summarise(Mean = mean(Coefficient), SD = sd(Coefficient), .groups = "drop")
```

Both models produce similar individual-level estimates for the selected
physicians. With 23 monthly observations per physician, the individual
likelihood contributes most of the posterior information at the
physician level in this application.

## Posterior Inference on Physician Segment Coefficients

The models differ in how they characterize the expected coefficient $\Delta(Z)$ for a representative physician with demographics $Z$. We compare these segment-level predictions for the same two physicians, using the `predict` function.

```{r representative-physician, results = "hide", fig.width=12, fig.height=6, fig.align='center', out.width="90%", dpi = 200, fig.cap="Posterior Distributions of Expected Physician Segment Coefficients."}
Z_seg <- list(Z = Z[physicians, ])
DeltaZ_lin  <- predict(out_lin, newdata = Z_seg, type = "DeltaZ+mu", burn = burn)
DeltaZ_hart <- predict(out_hart, newdata = Z_seg, type = "DeltaZ+mu", burn = burn)

deltaZ_draws <- bind_rows(
  Linear = as.data.frame(t(DeltaZ_lin[, k, ])),
  HART   = as.data.frame(t(DeltaZ_hart[, k, ])),
  .id = "Model"
) %>%
  setNames(c("Model", "Segment 1", "Segment 2")) %>%
  pivot_longer(-Model, names_to = "Segment", values_to = "Coefficient") %>%
  mutate(Model = factor(Model, levels = models))

ggplot(deltaZ_draws, aes(x = Coefficient, fill = Segment)) +
  geom_histogram(aes(y = after_stat(density)), bins = 45, alpha = 0.6,
                 position = "identity") +
  facet_wrap(~Model) +
  theme_classic(base_size = 16) +
  theme(legend.position = "top", legend.title = element_blank()) +
  labs(title = "Posterior Distributions of Expected Detailing Coefficients",
       x = "Coefficient Value", y = "Density")
```

```{r segment-comparison}
deltaZ_draws %>%
  group_by(Model, Segment) %>%
  summarise(Mean = mean(Coefficient), SD = sd(Coefficient), .groups = "drop")
```

For the selected physicians, segment-level posterior locations are
consistent with the corresponding individual-level posteriors shown
above. The linear specification restricts segment means to an affine
function of demographics, while HART allows nonlinear and interaction
structure in $Z$ through $\Delta(Z)$.
