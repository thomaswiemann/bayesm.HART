## Introduction
  
This vignette illustrates how to estimate a hierarchical logit model with HART priors using the `bayesm.HART` package. Following Application I in Wiemann (2025), the HART logit model is applied to the `bank` conjoint dataset of Allenby and Ginter (1995) on out-of-state credit card design.

`bayesm.HART` uses a Hierarchical Additive Regression Trees (HART) prior.
This specifies the *representative consumer* as a nonparametric function
of observed characteristics. This vignette contrasts that HART logit
specification with a conventional hierarchical logit model where the
representative consumer is linear in characteristics.

The vignette proceeds in five steps:

1. Load and prepare data for use with `bayesm` and `bayesm.HART`
2. Run MCMC chains for fully Bayesian inference
3. Posterior inference on respondent-level part-worths
4. Posterior inference on consumer segment part-worths
5. Variance explained by demographics

## Conjoint Data of Allenby and Ginter (1995)

We use the `bank` dataset in `bayesm`, originally analyzed by Allenby
and Ginter (1995). The data include responses from 946 customers in a
telephone conjoint on credit card attributes. Respondents were part of a
new-market ("out-of-state") targeting exercise and each provided 14 to
17 binary choice responses. The dataset contains 14,799 binary responses
plus respondent age, income, and gender.

`bayesm` and `bayesm.HART` use the same data structure.

```{r setup}
library(bayesm.HART)
library(bayesm)
library(tidyr)
library(dplyr)
library(ggplot2)

data(bank)
choiceAtt <- bank$choiceAtt
hh <- levels(factor(choiceAtt$id))
nhh <- length(hh)
lgtdata <- vector("list", length = nhh)
for (i in 1:nhh) {
  y <- 2 - choiceAtt[choiceAtt[, 1] == hh[i], 2]
  X_temp <- as.matrix(choiceAtt[choiceAtt[, 1] == hh[i], c(3:16)])
  X <- matrix(0, nrow = nrow(X_temp) * 2, ncol = ncol(X_temp))
  X[seq(1, nrow(X), by = 2), ] <- X_temp
  lgtdata[[i]] <- list(y = y, X = X)
}
Z <- as.matrix(bank$demo[, -1])
Z <- t(t(Z) - colMeans(Z))  # bayesm requires de-meaned Z

Data <- list(lgtdata = lgtdata, Z = Z, p = 2)
```

## MCMC Estimation

We apply two models to the conjoint data: the HART logit model (Wiemann, 2025) and a conventional linear hierarchical logit model (Rossi et al., 2009). Both models are motivated by a latent utility model of consumer choice. The models differ only in how they capture preference heterogeneity: the linear approach models the relationship between a respondent's characteristics and their part-worths as a linear function $\Delta^\top Z_i$, while HART uses a sum-of-trees factor model $\Delta(Z_i)$ that allows nonlinearities and interactions.

For vignette runtime, we use 20,000 iterations (longer chains are recommended
in practice) and discard the first 250 draws. The linear model is fitted with
`bayesm::rhierMnlRwMixture` and the HART model with
`bayesm.HART::rhierMnlRwMixture`, which sets `hart_model = "normalized"` in
`Prior`. We use 20 trees per factor and keep other hyperparameters at
defaults.

```{r fit-models, cache = TRUE, results = "hide"}
set.seed(2025)
R <- 20000
keep <- 4
burn <- 250  # kept draws to discard
Mcmc <- list(R = R, keep = keep)

out_hart <- bayesm.HART::rhierMnlRwMixture(
  Data,
  Prior = list(ncomp = 1, hart_model = "normalized",
               bart = list(num_trees = 20)),
  Mcmc
)

out_lin <- bayesm::rhierMnlRwMixture(Data, Prior = list(ncomp = 1), Mcmc)
class(out_lin) <- "rhierMnlRwMixture"  # bayesm.HART methods for the bayesm fit
```

A simple diagnostic is the log-likelihood trace over MCMC iterations.
In this run, both chains appear to mix after the burn-in cutoff in the
traceplot below.

```{r mcmc-diagnostics, fig.width=8, fig.height=5, fig.align='center', out.width="90%", dpi = 200, fig.cap="MCMC Traceplot of the Log Likelihood."}
models <- c("Linear", "HART")
trace <- data.frame(
  Iteration = rep(seq_len(R / keep) * keep, 2),
  Model = rep(models, each = R / keep),
  LogLikelihood = c(out_lin$loglike, out_hart$loglike)
)

ggplot(trace, aes(x = Iteration, y = LogLikelihood, color = Model)) +
  geom_line(alpha = 0.8) +
  geom_vline(xintercept = burn * keep, linetype = "dashed") +
  theme_classic(base_size = 16) +
  theme(legend.position = "bottom", legend.title = element_blank()) +
  labs(title = "Log-Likelihood Trace Plots", x = "MCMC Iteration", y = "Log-Likelihood")
```

## Posterior Inference on Respondent-level Part-Worths

We examine the posterior distributions for two specific respondents: Respondent 146 (an older woman with low income) and Respondent 580 (a middle-aged man with moderate income). The comparison focuses on the out-of-state bank attribute.

```{r individual-betas, fig.width=12, fig.height=6, fig.align='center', out.width="90%", dpi = 200, fig.cap="Posterior Distributions of Individual-level Part-Worths."}
resp <- c(146, 580)
k <- 10  # Bank Out-of-State

beta_draws <- bind_rows(
  Linear = as.data.frame(t(out_lin$betadraw[resp, k, -(1:burn)])),
  HART   = as.data.frame(t(out_hart$betadraw[resp, k, -(1:burn)])),
  .id = "Model"
) %>%
  setNames(c("Model", "Respondent 146", "Respondent 580")) %>%
  pivot_longer(-Model, names_to = "Respondent", values_to = "Coefficient") %>%
  mutate(Model = factor(Model, levels = models))

ggplot(beta_draws, aes(x = Coefficient, fill = Respondent)) +
  geom_histogram(aes(y = after_stat(density)), bins = 45, alpha = 0.6,
                 position = "identity") +
  facet_wrap(~Model) +
  theme_classic(base_size = 16) +
  theme(legend.position = "top", legend.title = element_blank()) +
  labs(title = "Selected Posterior Distributions of Individual Out-of-State Part-Worths",
       x = "Coefficient Value", y = "Density")
```

```{r individual-betas-summary}
beta_draws %>%
  group_by(Model, Respondent) %>%
  summarise(Mean = mean(Coefficient), SD = sd(Coefficient), .groups = "drop")
```

Both models produce similar individual-level part-worth estimates for these two respondents. This similarity is expected: when respondents have many choice profiles (here, between 14 and 17), their individual-level posterior estimates are primarily driven by their own choice data rather than the first-stage prior.

Differences between HART and linear hierarchical models are typically
more visible when individual-level data are limited and estimation
depends more on the representative consumer.

## Posterior Inference on Consumer Segment Part-Worths

The model estimates how part-worths vary with demographics $Z$, where $\Delta(Z)$ represents the expected part-worth for a "representative" respondent with characteristics $Z$.

We predict preferences for two consumer segments. Segment 1 is defined as older female respondents with low income, while Segment 2 is defined as middle-aged male respondents with moderate income. We use the `predict` function to get the posterior draws of the expected part-worths for these selected segments.

```{r representative-respondent, results = "hide", fig.width=12, fig.height=6, fig.align='center', out.width="90%", dpi = 200, fig.cap="Posterior Distributions of Expected Part-Worths."}
Z_seg <- list(Z = Z[resp, ])
DeltaZ_lin  <- predict(out_lin, newdata = Z_seg, type = "DeltaZ+mu", burn = burn)
DeltaZ_hart <- predict(out_hart, newdata = Z_seg, type = "DeltaZ+mu", burn = burn)

deltaZ_draws <- bind_rows(
  Linear = as.data.frame(t(DeltaZ_lin[, k, ])),
  HART   = as.data.frame(t(DeltaZ_hart[, k, ])),
  .id = "Model"
) %>%
  setNames(c("Model", "Segment 1", "Segment 2")) %>%
  pivot_longer(-Model, names_to = "Segment", values_to = "Coefficient") %>%
  mutate(Model = factor(Model, levels = models))

ggplot(deltaZ_draws, aes(x = Coefficient, fill = Segment)) +
  geom_histogram(aes(y = after_stat(density)), bins = 45, alpha = 0.6,
                 position = "identity") +
  facet_wrap(~Model) +
  theme_classic(base_size = 16) +
  theme(legend.position = "top", legend.title = element_blank()) +
  labs(title = "Posterior Distributions of Expected Out-of-State Part-Worths",
       x = "Coefficient Value", y = "Density")
```

```{r segment-comparison}
deltaZ_draws %>%
  group_by(Model, Segment) %>%
  summarise(Mean = mean(Coefficient), SD = sd(Coefficient), .groups = "drop")
```

For the selected segments and focal coefficient, the posterior
distributions differ across model specifications. In this vignette run,
the HART posterior means for segment-level expected part-worths are more
separated than the corresponding linear-model means. This pattern is
consistent with the broader function class in HART, where
$\Delta(Z_i)$ allows nonlinear and interaction structure in demographics.

## Quantifying Explained Variance ($R^2$)

To quantify explained demographic heterogeneity, we compute a Bayesian
$R^2$ measure. This is the fraction of latent preference heterogeneity
explained by observed demographics $Z$.

Because this is a hierarchical model, the total variance of the part-worths decomposes into the variance of the predictions $\Delta(Z_i)$ across the population (the explained variance) and the unobserved structural heterogeneity $\Sigma_{kk}$ (the residual variance). By evaluating this at every MCMC iteration, we obtain a posterior distribution for the $R^2$.

```{r r-squared, fig.width=8, fig.height=5, fig.align='center', out.width="90%", dpi = 200, fig.cap="Posterior Distributions of Explained Variance ($R^2$) for Out-of-State Preferences."}
smry_lin  <- summary(out_lin, Z = Z, burn = burn, coefs = k)
smry_hart <- summary(out_hart, Z = Z, burn = burn, coefs = k)

r2_draws <- data.frame(
  Model = factor(rep(models, each = R / keep - burn), levels = models),
  R2 = c(smry_lin$r2$R2_draws, smry_hart$r2$R2_draws)
)

ggplot(r2_draws, aes(x = R2, fill = Model)) +
  geom_density(alpha = 0.6) +
  theme_classic(base_size = 16) +
  theme(legend.position = "top", legend.title = element_blank()) +
  labs(title = "Variance Explained by Demographics",
       x = expression(R^2), y = "Density")

# Posterior mean R2
tapply(r2_draws$R2, r2_draws$Model, mean)
```

The density plot summarizes posterior draws of explained variance for the
focal coefficient under each specification. In this run, posterior $R^2$
draws are shifted upward under HART relative to the linear
specification, indicating higher explained heterogeneity for the same
demographic inputs.
